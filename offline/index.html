ဖော်မြူလာ အသုံးပြုပုံ

လိုင်း တစ်လိုင်း = ဂဏန်း + ငွေ။ ငွေ က တစ်ကွက်စာ — ထွက်တဲ့ ဂဏန်း တစ်လုံး စီ အဲ့ ငွေ ရတယ်။ ကွက် = ထွက်တဲ့ ဂဏန်း အရေအတွက်။ အောက် က ဥပမာ အားလုံး parser နဲ့ စစ်ပြီးသား။

၁။ အခြေခံ — ဂဏန်းတလုံး

123=500 → 1 ကွက် · 500

ဂဏန်းနဲ့ငွေကြား = ဒါမှမဟုတ် space ခံပေးတယ်: 123 500 လည်း အတူတူ။

၂။ စာရင်း — ဂဏန်း အများကြီး တစ်လိုင်း

123,456=500 → 2 ကွက် · 1,000

ကြား separator: - ~ , . * : / ရ။ = နဲ့ ဆက်ရေးရင် နောက် ဆုံး ငွေ အတူတူ ရတယ်: 750=755=214=1000 → 3 ကွက် · 3,000။

၃။ ပတ်လည် — ဂဏန်း လှည့်

123@500 → 6 ကွက် · 3,000 (123 132 213 231 312 321)

marker: @ R r အာ။ ဂဏန်း ထပ်ရင် ကွက် လျော့တယ်: 113@500 → 3 ကွက် · 1,500 (113 131 311)။

၄။ ဒဲ့ + ကျန် — ဈေး ၂ မျိုး

123ဒဲ့1000အာ500 → 123 က 1,000, ကျန် 5 လုံး က 500 စီ = 6 ကွက် · 3,500

ကျန် / ကျန်အာ လည်း အတူတူ။ စာရင်း + split: 123-531-487=6000R1000 → စာရင်း 3 လုံး 6,000 စီ + ကျန် perms 15 လုံး 1,000 စီ = 18 ကွက် · 33,000။

Rule B: တဆက်တည်း တူ digit-set တွေ က တစ်အုပ်: 236-263=5000ကျန်1000 → 2 လုံး 5,000 + ကျန် 4 လုံး 1,000 = 6 ကွက် · 14,000။ တခြား set ကြားခံရင် အုပ် ပြတ်တယ်။

၅။ / နဲ့ စီးရီး

/23=500 → 023…923 = 10 ကွက် · 5,000

/ = ဂဏန်း 0-9 တစ်လုံး ကိုယ်စား။ 2-digit + စီးရီး: 29ထိပ်စီးရီး500 → 029…929 (10)၊ 29နောက်စီးရီး500 → 290…299 (10)၊ 29အလယ်စီးရီး500 → 209…299 (10)။

၆။ ထိပ် / နောက် / အလယ် — 100 ကွက်

5ထိပ်500 → 500…599 = 100 ကွက် · 50,000

5နောက်500 → 005…995 (100)၊ 5အလယ်500 → 050…959 ပုံစံ (100)။ ရှေ့ = ထိပ်၊ လယ် = အလယ်။

၇။ ပူး — ၂ လုံး တူ

နောက်ပူး500 → 100 ကွက် · 50,000 (နောက် 2 လုံး တူ XYY)

ထိပ်ပူး / ရှေ့ပူး = ရှေ့ 2 လုံး တူ (YYX) — 100 ကွက်။ ဂဏန်း + ပူး = 10 ကွက်: 5နောက်ပူး500 → 055…955၊ 5ထိပ်ပူး500 → 550…559။ triples ပါတယ်။

၈။ ထွိုင် + ရာပြည့်

ထွိုင်500 → 000…999 = 10 ကွက် · 5,000

/// လည်း အတူတူ။ ရာပြည့်500 → 100…900 = 9 ကွက် · 4,500 (000 မပါ)။

၉။ အခွ — ရှေ့ = နောက်

အခွ500 → 010…989 = 90 ကွက် · 45,000

ရှေ့ = နောက်, အလယ် မတူ (XYX)၊ triples မပါ။ အခွ အပြည့်ရေး — ခွေ ချည်း မရဘူး။

၁၀။ အပါ — ဂဏန်း ပါတဲ့ အကုန်

1အပါ500 → 271 ကွက် · 135,500 (triples ပါ)

အပါ အပြည့်ရေး — ပါ ချည်း မရဘူး။

၁၁။ ဘရိတ် — digit-sum

5ဘရိတ်500 → 100 ကွက် · 50,000

ဂဏန်း 1 လုံး + ဘရိတ် = digit-sum အဲ့ ဂဏန်း နဲ့ ဆုံးတဲ့ အကုန်။ 0ဘရိတ် = 10ဘရိတ်၊ ပွင့် = ဘရိတ်။ အလွတ် ဘရိတ် မရှိ — ဘရိတ်500 ချည်း မရဘူး။

၁၂။ Split ဈေး + ကွင်းငွေ

123=1500/500 → ဒဲ့ 1,500 + ကျန် 5 လုံး 500 = 6 ကွက် · 4,000

123.456(500) / 123.456{500} → 2 ကွက် · 1,000။ 387...500r100 → ဒဲ့ 500 + ကျန် 5 လုံး 100 = 6 ကွက် · 1,000။

၁၃။ ပိတ်ဂဏန်း ဖယ်နည်း

5ထိပ်5500{-500} → 99 ကွက် · 544,500

ပိတ်ဂဏန်း ပါတဲ့ လိုင်း ပိတ်ခံရရင် {-...} နဲ့ ဖယ်ထုတ်: {-447/474/744} ပုံစံ လည်း ရ။ paste နဲ့ ရိုက် — ကီးဘုတ်မှာ { } မရှိ။

၁၄။ မရတာများ

ဘရိတ်500 (အလွတ်)၊ 5စီးရီး500 (1-digit စီးရီး မရှိ)၊ 123.456.500 (dots ချည်း ငွေ မပါ) — အကုန် invalid။ ခွေ pool ဖော်မြူလာ မရှိ၊ ထိုင် ဆိုတာ မရှိ။

၁၅။ တွဒ် အကျဉ်း

ပေါက်ဂဏန်း W ရဲ့ perms (W မပါ) + W-1 + W+1 = တွဒ် set။ အဲ့ ဂဏန်း ထိုးထားရင် stake × တွဒ် rate ရတယ်၊ W ကိုယ်တိုင် က အဆ ရတယ်။
